DataTalk — AI-Powered CSV Analysis

Overview

An interactive web application that enables users to upload CSV files and converse with their data using natural language. The AI assistant can generate visualizations, perform statistical analyses, and provide data-driven insights through an intuitive chat interface.

Goal

To democratize data analysis by allowing anyone to explore and understand their datasets without needing programming knowledge or data science expertise.

Screenshots

Key Features

  • Natural language queries for data exploration
  • Automatic chart generation (histograms, correlation heatmaps, bar charts, boxplots)
  • Real-time statistical summaries and data profiling
  • AI-generated insights report with executive summary and recommendations
  • Code execution sandbox for custom data transformations
  • Dark-themed, newspaper-inspired UI design

Technical Implementation

  • Google Gemini 2.0 Flash API for conversational AI
  • Pandas for data manipulation and analysis
  • Matplotlib for dynamic visualization generation
  • Gradio for interactive web interface
  • REST API integration (no heavy SDK dependencies)
